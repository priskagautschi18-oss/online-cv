# Online CV - Priska Jenny Gautschi

This repository contains my responsive online curriculum vitae.

## Features

- Responsive layout for smartphones, tablets and desktop computers
- Education, skills, achievements, projects and references
- Animated skill bars
- Clickable application photo with random fun facts
- Interactive project image gallery
- Hidden console Easter egg
- Password redirect to the protected CV page

## Technologies

- HTML
- CSS
- JavaScript
- Git

## Password Login

The entered password is used as the filename of the protected CV page.

The password and protected filename are not stored in the JavaScript code or documented here.

This is only pseudo-security for a static school project. Real protection would require server-side authentication.
